Rock Paper Scissors

This is a simple Rock Paper Scissors game made with Python.
The player chooses the number of rounds and then selects Rock, Paper, or Scissors in each round. The computer makes a random choice, and the scores are updated based on the winner of each round.
At the end, the program shows the final scores and the winner.

Library used

* random

What I understood

I learned how to use loops, conditions, user input, and the `random` module to make a simple game in Python.
